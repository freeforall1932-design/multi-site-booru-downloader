Simulating failures

Put a directive tag in a search box to exercise the shared failure taxonomy:

  • force:401 → authentication failure
  • force:429 → rate limited / network category
  • force:html → endpoint mismatch (HTML instead of JSON)
  • force:503 → server error with retry backoff

Filters behave like the real sites: -rating:explicit exclusions are appended from the per-server rating filter.
